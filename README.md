# TFM - Comparación EDAR

Proyecto de análisis comparativo entre plantas EDAR mediante Python, Streamlit y visualización interactiva.

## Objetivos

- Comparar comportamiento operacional de EDAR
- Analizar cargas contaminantes
- Visualizar tendencias mensuales
- Generar dashboard técnico interactivo

## Tecnologías utilizadas

- Python
- Pandas
- Plotly
- Streamlit
- Matplotlib
